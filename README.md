# CBST 训练器

> 面向中文用户的沟通与思维练习工具：从识别感受和想法开始，练习更具体地表达、回应与展开对话。

[在线体验](https://cbst-dialogue-mvp.vercel.app) · [使用手册](https://cbst-dialogue-mvp.vercel.app/manual.html) · [产品 Wiki](https://github.com/guoqiubin/cbst-dialogue-mvp/wiki) · [版本记录](./CHANGELOG.md)

## 这是什么

CBST 训练器将案例生成、文字练习与结构化反馈放在同一处。它不试图提供唯一正确的话术，而是帮助学习者在日常沟通中：

- 看见一句话里可能被概括、绝对化或混淆的部分；
- 更准确地识别和表达自己的情绪；
- 在回应他人时先承接体验，再讨论问题、选择和下一步；
- 用可练习的方式熟悉 CBST 对话中的逻辑字词与提问思路。

本项目适合想提升沟通、共情、情绪表达与思维澄清能力的中文学习者，也适合将它作为课程练习、读书会讨论或个人反思的辅助工具。

> 本工具用于学习和自我观察，不构成心理诊断、治疗建议、医疗意见或危机干预。

## 从哪里开始

第一次使用可直接打开 [全站使用手册](https://cbst-dialogue-mvp.vercel.app/manual.html)。如果你想快速开始，可按下面的路径选择：

| 你现在想练习什么 | 推荐入口 | 会得到什么 |
| --- | --- | --- |
| 判断一句话是否过于绝对、跳跃或混淆 | [认知谬误识别](https://cbst-dialogue-mvp.vercel.app/cognitive.html) | 基于原文的可能模式、证据与简明解释 |
| 练习完整的双人沟通 | [CBST 对话](https://cbst-dialogue-mvp.vercel.app) | AI 场景、连续回应与对话点评 |
| 练习把笼统判断问得更具体 | [逻辑字词训练](https://cbst-dialogue-mvp.vercel.app/logic-training.html) | 逻辑字词策略地图与回应反馈 |
| 练习接住对方的感受 | [共情训练](https://cbst-dialogue-mvp.vercel.app/empathy.html) | 单轮回应反馈与可分享的题目解析长图 |
| 更准确地说出自己的感受 | [情绪识别训练](https://cbst-dialogue-mvp.vercel.app/emotion.html) | 中文情绪词、强度和情境表达练习 |
| 练习先听懂对方再回应 | [倾听训练](https://cbst-dialogue-mvp.vercel.app/listening.html) | 反映式倾听反馈与参考回应 |

## 核心模块

### CBST 对话

设置关系场景、双方角色与事件背景后，由 AI 生成对话开场。学习者持续回应，自主决定结束时机，再获得围绕共情、逻辑字词与对话推进的点评。

### 认知谬误识别

输入一句话、一段独白或最多两人对话，系统识别其中可能存在的认知或逻辑偏差。返回结果不会强行凑数量；若原文不足以判断，或未发现明显模式，也会如实说明。

### 逻辑字词训练

面对一句生活化表达，先独立选择可能有帮助的逻辑字词，可选补写一句回应。提交后查看自己的策略、其他可行路径与不同策略的处理思路。

### 共情训练与情绪识别

共情训练随机给出一条情绪表达，学习者用自己的话回应。可选择单一或复杂情绪，重点练习承接体验，避免过早评价或给建议。情绪识别是其子训练，用分层中文情绪词、时间/行为语境和 1–10 强度刻度，帮助把“我很难受”说得更具体。

遇到明确的自伤、伤人或即时危险表达时，训练会优先切换到安全支持与现实求助的学习边界，而不是把它作为普通共情题处理。

### 倾听训练

倾听训练以反映式倾听为起点：面对一段“对方”的真实表达，用自己的话回应其事实、情绪与在意点，确认自己是否理解。系统会围绕准确性、是否避免过早建议或评价、是否减少未经表达的推断给出反馈，并提供 1 至 3 句参考回应。简短确认理解的追问可以使用，但不鼓励连续盘问。

### 使用手册与知识库

- [全站使用手册](https://cbst-dialogue-mvp.vercel.app/manual.html) 说明各模块适合谁、如何开始与推荐练习顺序。

## 进度与数据

- 未登录时，部分草稿、精选与近期分析记录保存在当前浏览器。
- 登录后，训练进度可同步到云端，以便在不同设备继续使用。
- 清除浏览器数据、换设备或未登录时，本机记录可能无法恢复。

详细说明见 [Wiki：进度与账户](./docs/wiki-source/进度与账户.md)。

## 本地运行

### 前置条件

- Node.js 18 或更高版本
- OpenAI API 密钥
- 如需登录、云端同步和知识库后台：一个已配置的 Supabase 项目

### 启动步骤

```bash
npm install
cp .env.example .env
npm run dev
```

打开 `http://127.0.0.1:3000`。管理员后台入口为 `http://127.0.0.1:3000/admin/`。

`.env` 中需要的变量及用途见 [部署说明](./DEPLOYMENT.md)。其中 `SUPABASE_SERVICE_ROLE_KEY` 只能存在于服务端环境变量，绝不能提交到仓库或暴露给浏览器。

## 安全、隐私与公开边界

- 不提交 API Key、Token、Cookie、`.env`、`.vercel/` 或真实用户数据。
- 不将课程原始资料、管理后台信息或未经项目负责人明确授权的联系方式、二维码作为公开项目素材。
- 当前网站的企业微信二维码为项目负责人确认可公开的产品联系入口；其他联系方式仍应默认视为私有内容。
- 文本分析、对话生成与题目生成会通过服务端调用模型服务；请勿输入不希望被处理的敏感个人信息。
- 项目当前未附带开源许可证。除另有书面授权外，代码与内容不自动授予商业再利用许可。

发布前的完整检查项见 [公开发布说明](./docs/公开发布说明.md)。
