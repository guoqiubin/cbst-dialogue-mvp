# CBST 对话练习器

一个面向中文用户的训练工具，当前包含五类独立练习模块：

- **CBST 对话**：由 AI 生成双人生活化场景，用户进行多轮回应，并获得 CBST 对话点评。
- **认知谬误识别**：分析一句话、独白或最多双角色对话中可能存在的认知扭曲或逻辑谬误，并给出原文证据、简明解释与来源依据。
- **CBST 逻辑字词训练**：一句话出题，用户无提示选择逻辑字词，可选补写回应；AI 提供可行策略地图、三档语义反馈与课程依据。
- **共情训练**：随机生成一句真实情绪表达，用户完成单轮回应；AI 聚焦是否接住体验、是否避免过早建议，并在高风险表达中优先评估安全干预。
- **情绪识别训练**：通过中文分层情绪词库、时间或行为语境与 1–10 强度刻度，练习把宽泛感受说得更具体。
- **情绪识别训练**：通过中文分层情绪词库、时间段与 1 至 10 分强度，练习把笼统感受表达为完整、可被理解的句子。

## 课程知识库

出题与点评会检索项目内的 CBST 课程规则，而不是只依赖模型泛化知识。课程资料可在私有后台 `/admin/` 上传为草稿，审核发布后才会参与训练；维护方式见 [KNOWLEDGE_BASE_WORKFLOW.md](./KNOWLEDGE_BASE_WORKFLOW.md)。

## 功能概览

- 真实 OpenAI API 驱动的案例生成、对话延续、对话点评和文本分析
- 受控术语库、同义概念去重、最多五项结果与非诊断式表达
- “无谬误”与“上下文不足”两种克制的反馈分支
- 小编精选、本机草稿和最近分析记录
- 已登录用户的训练进度云端同步
- 私有课程资料库：PPTX、PDF、DOCX、Markdown、TXT 与直接粘贴文本自动提取、审核发布、撤回和 30 天恢复期
- Grainy Gradient 暖色颗粒视觉风格

## 本地运行

1. 安装 Node.js 18 或更高版本。
2. 在项目目录中复制 `.env.example` 为 `.env`。
3. 在 `.env` 中填写 `OPENAI_API_KEY`、`SUPABASE_URL`、`SUPABASE_PUBLISHABLE_KEY`。
4. 若要启用知识库后台，再填写仅服务端使用的 `SUPABASE_SERVICE_ROLE_KEY` 与 `ADMIN_EMAILS`；这两项绝不应提交到 Git。
5. 运行 `npm run dev`。
6. 打开 `http://127.0.0.1:3000`；管理员后台为 `http://127.0.0.1:3000/admin/`。

## 安全与隐私

- `.env` 已被 Git 忽略，不应提交 API 密钥。
- `SUPABASE_SERVICE_ROLE_KEY` 仅能存在于服务端环境变量，不能放入浏览器代码、公开配置或 GitHub。
- 文本分析、CBST 对话与案例生成通过本地服务转发至 OpenAI API。
- 小编精选、草稿和分析历史仅保存于当前浏览器；清除浏览器数据、更换设备或浏览器后无法恢复。
- 本工具仅供学习与自我观察，不构成心理健康诊断、治疗建议、医疗意见或危机干预。
