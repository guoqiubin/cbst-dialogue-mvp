# CBST 对话练习器

一个面向中文用户的本地 MVP，包含两类练习工具：

- **CBST 对话**：由 AI 生成双人生活化场景，用户进行多轮回应，并获得 CBST 对话点评。
- **认知谬误识别**：分析一句话、独白或最多双角色对话中可能存在的认知扭曲或逻辑谬误，并给出原文证据、简明解释与来源依据。

## 功能概览

- 真实 OpenAI API 驱动的案例生成、对话延续、对话点评和文本分析
- 受控术语库、同义概念去重、最多五项结果与非诊断式表达
- “无谬误”与“上下文不足”两种克制的反馈分支
- 小编精选、本机草稿和最近分析记录
- Grainy Gradient 暖色颗粒视觉风格

## 本地运行

1. 安装 Node.js 18 或更高版本。
2. 在项目目录中复制 `.env.example` 为 `.env`。
3. 在 `.env` 中填写 `OPENAI_API_KEY`，不要将该文件提交到 Git。
4. 运行 `npm run dev`。
5. 打开 `http://127.0.0.1:3000`。

## 安全与隐私

- `.env` 已被 Git 忽略，不应提交 API 密钥。
- 文本分析、CBST 对话与案例生成通过本地服务转发至 OpenAI API。
- 小编精选、草稿和分析历史仅保存于当前浏览器；清除浏览器数据、更换设备或浏览器后无法恢复。
- 本工具仅供学习与自我观察，不构成心理健康诊断、治疗建议或医疗意见。

## 检查

运行 `npm run check` 可执行基础语法检查。
