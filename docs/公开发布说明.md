# 公开发布说明

本文件用于维护 CBST 训练器公开仓库的安全边界。它不是用户使用说明，而是每次提交前的复核清单。

## 可以公开

- 页面结构、样式、通用交互与脱敏后的示例内容。
- 经过确认可公开使用的品牌标识、图标和截图。
- README、CHANGELOG、使用说明、公开环境配置示例。
- 不包含课程原文、个人信息或管理信息的通用训练规则。

## 不应公开

- API Key、Token、Cookie、`.env`、部署配置中的密钥。
- 服务端权限密钥、Supabase 管理凭据、管理员邮箱列表。
- 真实用户输入、训练记录、账户信息、学员数据。
- 未经项目负责人明确授权的二维码、个人照片、手机号、邮箱、地址与其他联系方式。
- 未确认授权的课程原件、课件截图、人物头像、音频或第三方商业素材。

## 发布前检查

- [ ] `git status --short` 中没有临时文件、下载文件或本地缓存。
- [ ] 没有 `.env`、`.vercel/`、浏览器数据或密钥进入暂存区。
- [ ] 页面示例、截图和文档中没有真实用户数据或联系方式。
- [ ] 如需公开企业微信二维码或业务联系方式，已获得项目负责人对具体资源与展示位置的确认。
- [ ] 新增图片已确认来源和公开授权。
- [ ] `npm run check` 通过。
- [ ] README 的线上地址、模块入口和版本记录与当前项目一致。
- [ ] 若变更涉及线上行为，已在生产或预览环境走通关键路径。

## 已进入 Git 历史的敏感信息

`.gitignore` 只能阻止未来提交，不能从历史提交中移除文件。若发现密钥、二维码、用户数据或其他敏感资源已被提交：

1. 立即撤销或轮换相关密钥。
2. 停止继续复制或引用该资源。
3. 评估是否需要重写 Git 历史；这是会改变公开提交历史的操作，应由仓库负责人确认后执行。
4. 在完成清理前，不要把该仓库视为已完成脱敏的公开作品集。
