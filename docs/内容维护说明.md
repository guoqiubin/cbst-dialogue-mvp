# 内容维护说明

本说明面向课程内容维护者与运营人员，帮助在不破坏训练页面的前提下更新资料。

## 课程知识库

1. 登录私有后台 `/admin/`。
2. 上传 PPTX、PDF、DOCX、Markdown、TXT，或粘贴已整理的文本。
3. 选择适用训练模块，核对解析后的摘要和文本范围。
4. 发布后，资料才可能被出题与点评检索使用。
5. 上传错误时使用删除/撤回功能；删除前确认不会影响仍需引用的内容。

具体的技术流程与恢复期见 [知识库工作流](../KNOWLEDGE_BASE_WORKFLOW.md)。

## 新增训练内容的原则

- 先明确模块目标、目标学习者、输入形式和反馈边界。
- 一条内容使用稳定 ID，不依赖数组下标；新增内容不能改变既有内容的 ID。
- 题目避免重复同一生活事件，兼顾积极、消极与复杂情绪，但不强行制造问题。
- 对心理健康相关内容使用学习和沟通语言，不做诊断、人格贴标签或替代专业帮助。
- 涉及自伤、伤人或即时危险时，优先给出现实安全支持与求助方向，不作为普通训练题延展。

## 每次更新后的记录

更新用户可见内容、知识库规则或模块流程后：

1. 在 `CHANGELOG.md` 记录版本、日期、变化和影响范围。
2. 若改变用户操作路径，同步更新 README 与 Wiki。
3. 新模块先在 `CBST_DIALOGUE_PRD.md` 记录已确认范围、边界和暂不实现项；上线后同步更新 `docs/wiki-source/训练模块说明.md`、FAQ、使用手册与版本记录。
3. 运行 `npm run check`，并手动检查对应模块的主要流程。
4. 上传或替换素材前确认公开授权与隐私边界。
