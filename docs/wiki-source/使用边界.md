# 使用边界

## 本工具不做什么

- 不进行心理疾病诊断、人格诊断或医疗判断。
- 不替代心理治疗、危机干预、医疗机构或其他专业服务。
- 不保证每一条 AI 反馈都适用于真实关系中的所有情境。
- 不应被用于判断他人“有问题”、给他人贴标签或替代现实沟通。

## 安全优先

如果现实中存在明确自伤、伤人或即时危险，请停止把问题停留在练习页面，优先联系当地紧急服务、医疗机构、危机干预资源或可信赖的人。

## 隐私建议

请避免输入姓名、联系方式、地址、证件信息、账户信息、未公开工作内容或其他不希望被处理的敏感个人信息。

## 版权与内容

课程资料、品牌素材与第三方资源应在确认来源和授权后使用。公开仓库不应包含原始课件、未授权人物图片或私有运营素材；经项目负责人明确授权的业务联系入口可作为例外公开。
