# 进度与账户

## 不登录也可以训练吗？

可以。大多数训练页面无需登录即可开始。

## 不登录时，记录保存在哪里？

草稿、精选或最近分析等部分记录保存在当前浏览器。清除浏览器数据、使用无痕模式、换浏览器或换设备后，记录可能丢失。

## 登录后有什么变化？

登录后，支持云端同步的训练进度会保存到你的账户中，以便在不同设备继续。页面会明确显示“已登录 · 云端同步”。已登录状态下不需要重复登录，并可以随时退出。

## 密码由谁保存？

密码由认证服务处理，训练器不会读取或保存你的明文密码。

## 使用公共设备时要注意什么？

完成训练后请退出登录；不要将浏览器设置为长期保存登录状态；不要输入不希望被处理的敏感个人信息。
