# 第一次使用

无需先完成全部训练。选择你当下最想提升的能力，完成一题或一段对话即可。

## 第一步：选一个入口

- 想理解一段话中的思维模式：进入 **认知谬误识别**。
- 想知道怎么回应别人的情绪：进入 **共情训练**。
- 想训练提问与逻辑字词：进入 **逻辑字词训练**。
- 想练习完整对话：进入 **CBST 对话**。

如果不知道如何选择，先完成一轮 [情绪识别训练](https://cbst-dialogue-mvp.vercel.app/emotion.html)，再进入共情训练。

## 第二步：先写自己的判断

训练的价值不在于记住固定答案。看到题目后，先按真实理解作答，再查看反馈：

- 共情训练中，先回应对方体验，不急着评价、解释或给建议。
- 逻辑字词训练中，先选择你认为能帮助对方思考的字词，再看策略地图。
- 认知谬误识别中，直接粘贴需要检验的表达；结果只提示可能模式，不替你给人下结论。

## 第三步：用反馈继续下一题

反馈会说明已做到的部分、可以调整的方向、可行策略或下一步问题。它是练习提示，不是标准答案。

共情训练完成点评后，可将本题和解析生成长图，用于个人复盘或分享；生成发生在当前浏览器中。

## 第四步：需要保存时再登录

未登录时，部分记录只保存在当前浏览器。登录后，训练进度可同步到云端，便于更换设备后继续。不要在公共设备保存登录状态。
