# 版本记录

完整记录见主仓库的 [CHANGELOG.md](https://github.com/guoqiubin/cbst-dialogue-mvp/blob/main/CHANGELOG.md)。

## v0.1.4 · 2026-11-12

- 倾听训练新增训练历史，自动保存题目、用户回应与解析；登录后同步到云端。
- 新增“导出本题图片”，可一键下载题目、我的回应和解析组成的 PNG 图片。

## v0.1.3

- 新增登录后可同步的勋章墙，覆盖各模块首次完成、累计练习和全模块覆盖。
- 勋章只记录练习累计信息，不保存训练原文。

## v0.1.1 · 2026-11-03

- 完善公开项目介绍、使用入口与 Wiki 页面结构。
- 增加面向非开发者的模块说明、FAQ、进度说明与内容更新说明。
- 明确公开仓库与私有运营资源之间的边界。

- 上线 CBST 对话、认知谬误识别、逻辑字词训练、共情训练和情绪识别训练。
