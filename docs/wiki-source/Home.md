# CBST 训练器：产品介绍与使用入口

CBST 训练器是一个面向中文用户的沟通与思维练习工具。它把情绪识别、共情回应、逻辑澄清与多轮对话练习放在同一个网站中，帮助学习者把“我应该怎么说”变成可反复练习的具体能力。

## 适合谁

- 想更准确识别自己的感受、想法与表达方式的人。
- 想练习在亲密关系、家庭、校园或工作沟通中先听见对方，再讨论问题的人。
- 想把“一定、总是、都不喜欢我”这类笼统判断拆得更具体的人。
- 希望将课程知识转化为日常练习的读书会、课程学习者或带领者。

## 从哪里开始

| 你遇到的情况 | 从这里开始 |
| --- | --- |
| 不确定一句话有没有过度概括或跳跃判断 | [认知谬误识别](https://cbst-dialogue-mvp.vercel.app/cognitive.html) |
| 想先把“难受”说得更具体 | [情绪识别训练](https://cbst-dialogue-mvp.vercel.app/emotion.html) |
| 想练习如何回应一位有情绪的人 | [共情训练](https://cbst-dialogue-mvp.vercel.app/empathy.html) |
| 想练习用问题推动思考，而不是直接说教 | [逻辑字词训练](https://cbst-dialogue-mvp.vercel.app/logic-training.html) |
| 想完成一段完整的双人模拟对话 | [CBST 对话](https://cbst-dialogue-mvp.vercel.app) |

## 推荐练习路径

1. 从 **情绪识别训练** 练习命名感受、强度和情境。
2. 进入 **共情训练**，练习先承接体验，不急着给建议。
3. 使用 **逻辑字词训练**，把绝对化或含混的表达问得更具体。
4. 最后进入 **CBST 对话**，在完整场景中综合练习。

这不是唯一正确路径。你也可以只选择当前最想练习的一个模块开始。
