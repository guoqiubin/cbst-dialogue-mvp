CBST 对话法参考

理解 CBST 在训练什么

课件里的核心观点不是“用几句漂亮话安慰别人”，而是通过共情和逻辑提问，让对方产生思考、恢复自主感、看到更具体的问题、再走向下一步行动。它不是强行说服，也不是抢着替对方下结论。

沟通的常见误区

  • 评价、比较、读心，会忽略对方此刻的感受。
  • 强人所难、甩锅、否定感受，会把对话推向防守。
  • 代替对方判断，会削弱其自主感。

CBST 的对话目标

沟通不是让对方立刻听话或证明自己有道理，而是帮助对方开始思考；对方能思考，才更可能形成自主感、胜任感和归属感。

四阶段

  • 共情训练
  • 九种逻辑运用
  • 想办法训练
  • 后果思考与执行

推荐顺序

  • 先接住感受，再拆解问题。
  • 先把笼统判断变具体，再讨论方案。
  • 先让对方说清楚，再推动选择、行动或边界。

九类逻辑字词怎么用

1. 部分逻辑

一些 / 所有、百分比、或许 / 一定

作用：把“全部都不行”拆成“部分出了问题”。

2. 时间逻辑

之前 / 之后、现在 / 以后、一边 / 一边

作用：把“永远这样”改成“过程可变化”。

3. 是非逻辑

是 / 不是、相同 / 不同

作用：澄清定义、边界和误解。

4. 选择逻辑

和 / 或者、是 / 还是

作用：帮助看到不止一个选项。

5. 假设逻辑

如果 / 那么

作用：推动后果思考和执行判断。

6. 因果逻辑

为什么 / 因为

作用：寻找原因，不急着给评价。

7. 必要逻辑

想要 / 必要

作用：区分愿望和必须，减少僵化要求。

8. 相关逻辑

与……有关

作用：把问题和人格做分离。

9. 公平逻辑

公平 / 不公平

作用：帮助讨论关系中的尊重与边界。

案例一：考试失败时的典型思路

课件中的经典做法不是直接说“你不笨”“下次努力就好”，而是先问：是所有学科都糟糕，还是一些学科糟糕？这样能把“我很笨”拆回具体问题，再继续找出哪一类题没学懂、谁能帮助解决。

案例二：社交受挫时的典型思路

当孩子说“同学都不喜欢我”时，课件示范不是反驳，也不是说教，而是继续问：是所有同学都不喜欢，还是一些同学不喜欢？这样能把绝对化感受拆解成更真实的社交图景。

案例三：亲密关系里的边界

当对方以“玩笑”为名贬损你时，课件的思路是：先确认对方定义，再追问是否公平。关键不是回击，而是让对方看见逻辑后果与关系边界。

案例四：乐观解释风格

课件反复强调，要避免把问题说成永久、普遍、人格化。换句话说，不要轻易说“你总是”“你永远”“你就是……”；更好的做法是把问题限定在此刻、此事、此部分。

练习时你可以这样判断自己是否用对了

  • 我这句话是在接住感受，还是在急着管理对方？
  • 我有没有把“总是、全部、一定”拆成更具体的事实？
  • 我是在帮对方思考，还是替对方做判断？
  • 这轮对话有没有推进出新的信息、选择或下一步？
